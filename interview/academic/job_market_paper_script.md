# Job market paper — reading script (from practice)

---

My job market paper is about e-commerce return policy. Now suppose you are a consumer who shops on Taobao. At the checkout, you'll see a green label next to the product name. This label means the product is covered by return shipping insurance. So whenever you return a product with this return shipping insurance, part of your return shipping fee is reimbursed. This is the kind of policy I'm interested in. A return policy changes how costly a return is, and therefore a consumer's willingness to pay. My job market paper evaluates existing return shipping insurance, then proposes a new policy that outperforms the existing one, and shows how the best return policy differs across products.

A return policy should encourage purchases and returns that generate positive social surplus. A return should occur if the seller's value of the product exceeds the consumer's value plus the shipping fee and the processing fee. A purchase should occur if the expected value generated when consumer keep the product exceeds the expected return cost. If a product is sold to a consumer who is most likely to return it, then this transaction shouldn't happen in the first place. Our main result is that there is a trade-off between purchase and return efficiency.

Consumers tend to over-return under full refund because they do not internalize the cost that falls on the seller. The return product may have a stain on it, which takes time and effort to clean and resell it. Tightening the return policy solves this excessive return, but it also makes consumers more likely to keep the product, which strengthens the seller's incentive to raise price. And this incentive to raise price can exclude valuable transactions when the profit margin is high. On the other hand, a more lenient return policy performs well by expanding valuable transactions when the profit margin is high, but at the cost of more over-return. This suggests a return policy should depend on the profit margin.

Actually, which return policy the platform should use depends on factors other than profit margin. It also depends on how much scrap value the seller can recover from the return product and the degree of match value uncertainty. So if the scrap value is high, the return doesn't generate much loss. Therefore the seller doesn't need to worry about the returned product, and the priority should be given to expanding purchases. In this case, a lenient return policy will do the job.

Now we'll move to match value uncertainty. If the match value uncertainty is high, this means the consumer either super likes it or hates it. This creates a large option value, which makes the transactions valuable. Moreover, high match value uncertainty also makes the return rate less sensitive to the leniency of the return policy. This is because when the match value uncertainty is large, whether the consumer returns or keeps the product is mainly determined by the realized match value rather than how lenient the return policy is. So a generous return policy doesn't affect consumers' return rate a lot, and the distortion on the return margin is small.
