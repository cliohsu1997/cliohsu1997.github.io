My job market paper is about e-commerce return policies.

On Taobao, there is return shipping insurance. At checkout, you see a small box. If you check it, you pay a small premium up front. If you later return the item, the insurance partially reimburses the return shipping fee.

This is similar to what you see on Amazon. Beyond the typical return window, Amazon charges twenty percent of the restocking fee.

This is a type of return policy. Other return policies include a full refund, a partial refund, and a restocking fee.

A return policy changes how costly a return is, and therefore a consumer's willingness to pay.

My job market paper is about evaluating the existing return shipping insurance and proposing a new and alternative return policy that outperforms the existing ones.

Our main result is that there's a trade-off between encouraging more efficient purchases and enabling more efficient returns.

The intuition for inefficient returns is that consumers tend to over-return with a full refund, because they don't take into account the negative externality on the seller. For example, a stain on a garment takes time and effort for the seller to clean and resell.

## Practice session ? October 28

A return policy changes how costly a return is, and therefore shifts consumers' willingness to pay.

A return policy should encourage purchases and returns that generate positive social surplus.

A return generates positive surplus if the seller's value exceeds the consumer's value plus the return shipping cost and the processing cost.

A purchase should occur when the expected value generated exceeds the associated return cost ? in expectation, weighting by the probability of return. A purchase that is most likely to result in a return shouldn't occur in the first place.

Our main result is that there is a trade-off between purchase efficiency and return efficiency.

Consumers tend to over-return under a full refund because they don't take into account the negative externality on the seller. For example, a stain on the cloth takes time and effort for the seller to clean and resell.

A strict return policy solves excessive returns. However, when more consumers keep the product, the seller's incentive to set a high price becomes stronger, and this could potentially exclude valuable transactions. If you curb over-returns on the return margin, you may need to sacrifice efficiency on the purchase margin.
