# Job market paper — reading script (from practice)

---

My job market paper is about e-commerce return policy. Now suppose you are a consumer who shops on Taobao. At the checkout, you'll see a green label next to the product name. This label means the product is covered by return shipping insurance. So whenever you return a product with this return shipping insurance, part of your return shipping fee is reimbursed. This is the kind of policy I'm interested in. A return policy changes how costly a return is, and therefore a consumer's willingness to pay. My job market paper evaluates existing return shipping insurance, then proposes a new policy that outperforms the existing one, and shows how the best return policy differs across products.

A return policy should encourage purchases and returns that generate positive social surplus. A return should occur if the seller's value of the product exceeds the consumer's value plus the shipping fee and the processing fee. A purchase should occur if the expected value generated when consumer keep the product exceeds the expected return cost. If a product is sold to a consumer who is most likely to return it, then this transaction shouldn't happen in the first place. Our main result is that there is a trade-off between purchase and return efficiency.

Consumers tend to over-return under full refund because they do not internalize the cost that falls on the seller. When the returned product may have a stain on it, which takes time and effort to clean and resell it. Tightening the return policy solves this excessive return, but it also makes consumers more likely to keep the product, which strengthens the seller's incentive to raise price. And this incentive to raise price can exclude valuable transactions when the profit margin is high. On the other hand, a more lenient return policy performs well by expanding valuable transactions when the profit margin is high, but at the cost of more over-return when consumers receive the product.
