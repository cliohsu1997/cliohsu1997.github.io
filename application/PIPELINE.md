# Application pipeline

The agent skill **application-pipeline** (`~/.cursor/skills/application-pipeline/SKILL.md`) is the source of truth.

Short rules:

1. New JD → location folder → job folder + `job_info.md`
2. Update `application_list` (+ PDF)
3. If letters required → update `recommendation_letters_to_send` Excel + PDF (**Materials = letters only**)
4. **Complete** on the application list = applicant materials done; letters tracked separately
5. **Deadlines:** if Chinese/English or mirror posts disagree, **use the earliest hard deadline** everywhere, and note the others in `job_info.md`
